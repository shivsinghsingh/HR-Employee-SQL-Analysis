# HR Employee Data Analysis

## Project Overview
   This project analyzes HR Employee data using SQL to understand employee details, department,salaries,job roles and employment status.
   This main objective is to extract useful insights from employee data using SQL queries.

## Dataset Information
   The dataset contains 500 employee record.
 
    Key cloumns includ:
     -Employee ID
     -Employee Name
     -Gender 
     -Date of Birth
     -Department
     -Job Title
     -City
     -Joining Date
     -Salary
     -Emploment Status

## SQL Analysis
   The project uses SQL queries to analyze employee data and generate meaningful business insights.
   
   SQL concepts used:
   -SELECT
   -WHERE
   -ORDER BY
   -GROUP BY
   -HAVING 
   -COUNT()
   -AVG()
   -MAX()
   -MIN()
   -DISTINCT
   
## Key Insights
   The analysis helps identify;
   -Total number of employee
   -Employees in each department
   -Average salary by department
   -Highest and Lowest salary
   -Employees with higher salaries
   -Employees distribution by gender
   -Different job roles
   -Employee employment status
   -City-wise employee distribution 

## Conclusion
   This HR Employee Data Analysis project demonstrates how SQl can be used to analyze employee data and identity userful HR insights.
   The project provides a clear understanding of employee salaryies, department,job roles,gender, and employee status.
